# Plataforma de Estudo Bíblico

PWA/Web para estudo bíblico profundo, com a Bíblia no centro da experiência.

## Objetivo

Transformar a seleção de um versículo, perícope ou capítulo em uma bancada de estudo multidisciplinar, reunindo exegese, hermenêutica, história e arqueologia, teologia, idiomas bíblicos, referências cruzadas, debates, aplicação, homilética e consultoria bíblica com IA/RAG.

## Estado atual

Este repositório está sendo organizado a partir da versão corrigida auditada do protótipo. A auditoria identificou que a versão original era um frontend/protótipo avançado, mas não continha ainda a Bíblia completa, um modelo de IA real nem RAG completo.

Por segurança teológica e técnica, textos bíblicos ausentes não devem ser substituídos por texto fictício ou apresentados como Escritura.

## Arquitetura

React + TypeScript + Vite + PWA, com evolução planejada para dados bíblicos licenciados, motor de estudo, fontes verificáveis e consultor de IA ancorado no contexto selecionado.

Consulte ESPECIFICACAO_ARQUITETURAL_E_TEOLOGICA.md para a especificação completa.

## Princípio de confiabilidade

🟢 Fato/consenso · 🟡 Debate acadêmico · 🔴 Hipótese/reconstrução.

A plataforma deve evitar citações inventadas, referências inexistentes e textos bíblicos fabricados.
